STEP 6: HOW TO UPLOAD

Open the repo on GitHub and click Add file, then Create new file for each .md file. Type the folder path in the name box, such as products/capstone-project-tracker/README.md, and GitHub creates the folders.
For images, click Add file, then Upload files, and drag the PNGs into previews/.
Click Commit changes after each file.
To turn on GitHub Pages: Settings, then Pages, set the source to “Deploy from a branch,” pick main and / (root), then Save. Your site goes live in a few minutes.
